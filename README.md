# Juego de Pares

Juego de Pares
    Tematicas: Colores, Animales, Numeros (puede que falte registrar mas datos)
    Dificultad: Facil (3x3), Medio (4x4), Dificl (5x5)
    Idiomas: Español, Aymara e Ingles

Instrucciones:
1. Descargar dependencias- Ejecutar desde la terminar del proyecto
    flutter pub get
2. Generar los adaptadores de la db (Hive) (OBLIGATORIO!)
    flutter pub run build_runner build --delete-conflicting-outputs
3. Listo para Ejecutar (F5)- Mejor si usan su celular activando la depuracion USB
